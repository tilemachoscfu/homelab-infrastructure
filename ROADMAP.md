# Roadmap

The roadmap tracks improvements that make the homelab safer, easier to restore
and easier for others to understand.

Progress is managed on the public
[Homelab Roadmap board](https://github.com/users/tilemachoscfu/projects/1).

## Reliability

- [ ] Review qBittorrent, Gluetun and AirVPN throughput and port forwarding
- [ ] Add consistent health checks to every suitable service
- [ ] Document and test a full disaster-recovery procedure
- [ ] Define backup retention and periodic restore tests

## Operations

- [ ] Standardize container update and rollback procedures
- [ ] Add resource limits where measurements justify them
- [ ] Document disk-capacity alerts and SMART response procedures
- [ ] Add a sanitized service dependency inventory

## Documentation

- [ ] Add privacy-reviewed screenshots
- [ ] Add per-stack setup and troubleshooting notes
- [ ] Document Home Assistant integration boundaries
- [ ] Publish a hardware overview without serial numbers or unique identifiers

Completed work is recorded in [CHANGELOG.md](CHANGELOG.md).
